# WhisperDoc Technical Release Notes - v3.3.0
**Version Range: v3.2.0 to v3.3.0**

v3.3.0 adds **OpenRouter** as a third place to transcribe, beside your own WhisperDoc server and Groq. Pick it, paste an OpenRouter key, and choose from every speech-to-text model OpenRouter serves, listed live with its latency and ordered by accuracy. Zero data retention is enforced on every request unless you turn it off. The three sources now sit side by side at the top of **Account**. The Flutter client changes; the backend and terminal client are unchanged apart from the small fixes listed at the end.

---

## Upgrade Notes

Read these before updating:

- **Choosing a source moved**: **Switch service** is replaced by a three-way selector at the top of Account: **Self-hosted**, **Groq** and **OpenRouter**. Your current choice carries over.
- **OpenRouter is paid**: OpenRouter has no free speech-to-text. A dictation costs a fraction of a cent (about $0.0002–0.006 per audio minute, depending on the model), billed to your OpenRouter credits. Groq stays the free option.
- **Zero data retention is on by default**: With it on, only models with a host that keeps nothing are offered, and every request tells OpenRouter to refuse any other host. Turning it off asks first.
- **Output styles work on OpenRouter**: Clean, Pro, Casual, Tech and custom styles run through OpenRouter with the same rewrite model as on Groq (`qwen/qwen3.8-27b`, reasoning off), under the same retention setting. A rewrite takes a median of about 0.45 s there, against about 0.26 s on Groq.
- **Choose the rewrite model**: Account → OpenRouter → **Rewrite model** takes any OpenRouter model id; leave it empty for Qwen3.8 27B. Saving first sends the model a one-word rewrite, and a model that can't serve the styles is refused with the reason (no such id, no zero-retention host, or reasoning that can't be turned off).
- **Tech keeps your words and gets the terms right**: The Tech style no longer turns a dictation into a headed spec three times its length. It removes filler and writes code exactly: `get_user_by_id`, `routes/users.py`, `kubectl get pods -n staging`, `redis://localhost:6379`, with frameworks, platforms and protocols spelled as their makers do (FastAPI, Next.js, gRPC, OAuth 2.0). Steps you count off become a numbered list; nothing is added. On Groq it now answers in about 280 ms rather than 500–900 ms.
- **Server setup in one command, on any machine**: `./setup.sh` now generates the API key, picks GPU or CPU (a new `docker-compose.cpu.yml` runs Whisper without an NVIDIA GPU), builds, starts and waits until the server is healthy. It takes flags for unattended use (`--engine`, `--cpu`/`--gpu`, `--dev`, `--yes`), and CI runs it on every backend change.
- **Debug lines stay out of the Logs panel**: A release build no longer records debug-level lines in Account → Logs; they appear only when running from a development build.

## OpenRouter

### Choosing a model
- **The list is live**: The model picker shows what OpenRouter serves right now, from its own API. Nothing is hard-coded, so a new model appears and a retired one disappears without an app update. The last list is kept, so the picker opens instantly and works offline.
- **Most accurate first**: Each row shows the model, its maker and its live latency, with its word error rate (WER) on the right. WER is a fixed snapshot of Artificial Analysis's measurements on 23 Nov 2026, kept in the app; a model it never measured shows "—" and is listed after the measured ones.
- **Live latency**: The figure under each model is OpenRouter's median time to a full transcript over the last 30 minutes, weighted across the hosts it sends requests to, read when the picker opens (only for models without a recent figure).
- **Compare further**: **Compare on OpenRouter** opens OpenRouter's model table and **Accuracy leaderboard** opens Artificial Analysis's, both in the browser.
- **A sensible first pick**: Switching to OpenRouter chooses Microsoft's MAI-Transcribe 2 (2.0% word error), or, if OpenRouter stops serving it, the first model listed that isn't being retired.
- **Retirement is announced, never silent**: A model with an announced end date shows "retires 22 Dec" in the picker. If your model disappears, the home screen says `[ model retired ]` and **Choose** opens the picker. The app never switches models on its own.
- **Hosts**: OpenRouter picks the host for each request, among those that meet your retention setting.
- **Rewrites go to a quick host**: A rewrite asks for the lowest-latency host among those writing at least 200 tokens a second. That beat latency alone (median 0.45 s against 0.71 s for Qwen) because a rewrite is about 75 tokens, so the speed after the first one counts too. See [the rewrite model benchmark](../benchmarks/rewrite_models.md).

## Performance

- **The upload's connection opens while you talk**: Starting a cloud dictation opens the HTTPS connection the upload will use, and every cloud call shares one keep-alive client, so the upload doesn't wait on a fresh TLS handshake when you stop.
- **Long clips never stutter the UI**: Above 1 MiB, the clip's base64, JSON and UTF-8 encoding all run off the UI thread.
- **One copy less**: A finished clip is written into its WAV once, straight from the captured chunks.
- **Fewer rebuilds**: The home screen watches the model list only while OpenRouter is the source, and the list only notifies when something it affects changes.

---

## Reliability

- **A recording that can only fail never starts**: Before the microphone opens, by button or by hotkey, the client checks the source is ready: a key, and on OpenRouter a model it still serves that fits your retention setting. Otherwise it says what to fix instead of recording a clip that would be thrown away.
- **Clear errors per cause**: A cloud failure now says which service and what to do: an invalid key, a refused request, credits run out (OpenRouter), a retired model, no host that keeps zero data, a rate limit, no audio, or no connection (TLS and proxy failures included).

- **Only a stale connection is retried**: A kept-alive connection the server had already closed is sent once more; a dropped upload, a refused connection or any HTTP error is never retried, so nothing is billed twice.
- **Clips fit the 25 MB limit**: The longest clip is now about 9 min 17 s on OpenRouter and 12 min 34 s on Groq (from 12 min 30 s at 24 MiB, which could exceed the limit), counted in decimal megabytes with room for the request around it.
- **Screen readers keep up in Account**: Resting the pointer on a source in the selector no longer breaks Windows accessibility, which logged `Failed to update ui::AXTree` and left a screen reader reading a stale screen. Each source can now also be pressed from a screen reader.
- **One cloud path**: Groq and OpenRouter share the same buffering, size cap, sanitizing and error handling behind one engine interface, so a fix to one is a fix to both.

## Also in this release

- **Client**: package upgrades (`window_manager` 0.7.1 with Windows 11 frameless-border fixes, `flutter_web_auth_2` 6.1.0, `sqlite3` 3.9.2 with a shutdown crash fix, and five transitive packages).
- **Backend**: `.env.template` now sets `MIN_CLIENT_VERSION=3.0.0` and `SEC_CLIENT_VERSION=3.1.0` for new servers.
- **Terminal client**: message listeners are plain functions (the transport no longer awaits them), and the operational-error tests now assert the exact log line.
- **Docs**: the README is cut to the essentials and points to guides for [setup](../setup.md), [architecture and security](../architecture.md), [development](../development.md) (CI/CD, releases, contributing) and the [backend](../../backend/README.md). Sign-in is documented as working with any OIDC provider that signs RS256 tokens, with Authentik as the reference setup. Benchmarks live in [docs/benchmarks](../benchmarks/README.md), and `scripts/benchmark_prompts.py` reruns the style benchmarks with exactly what the client sends.
- **Backend build**: a local `uv sync` no longer forces a full Docker rebuild (`*.egg-info/` is ignored).
