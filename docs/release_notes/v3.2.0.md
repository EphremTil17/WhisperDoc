# WhisperDoc Technical Release Notes - v3.2.0
**Version Range: v3.1.0 to v3.2.0**

v3.2.0 rebuilds the Flutter client as **Captions**, a quiet crimson-on-black interface with one status cue, one action under it, and the last transcript set as captions. It also closes the client's remaining server-path security gaps. Your sign-in now goes only to servers you trust, a server can no longer paste text you didn't dictate, and the backend stops writing dictated words to its log. The backend changes only that log line; the terminal client is unchanged apart from a test fix.

---

## Upgrade Notes

Read these before updating:

- **Custom servers ask before your sign-in is sent**: The first time the client connects to a server other than the built-in one while you are signed in, the home screen shows `[ new server ]` and asks "Send your sign-in to <host>?". Nothing is sent until you press **Trust server**. The built-in server and developer-key connections are unaffected. Trusted servers are forgotten when you sign out or another account signs in.
- **The server has two minutes to return a transcript**: The client now accepts a transcript only after it ends a dictation, and only for two minutes. A CPU-only server that needs longer for a very long clip will have its text ignored. The client says so instead of pasting late.
- **Raw, Clean and Casual paste on one line**: Line breaks are joined into spaces for these styles, so a stray line break can't run a command in a terminal. Pro, Tech and custom styles keep their paragraphs.
- **Backend log no longer contains transcripts**: A finished transcription logs its length (`Transcription complete (24 chars)`), never its words, in either mode. Rebuild the backend image (`docker compose build backend`) to pick this up, and update any log tooling that read transcript text.
- **Settings moved**: Connection, sign-in, keys, model, language, version and logs live in **Account** (the person icon). Microphone, shortcut, copy and paste, and the moving background live in **Settings** (the sliders icon). Both are full-window panels that save each change on its own.
- **Fonts are bundled**: Lexend, JetBrains Mono and the Lucide icon font ship with the app, and `google_fonts` is removed, so the client no longer downloads fonts at startup.

## Security

### Sign-in scope
- **Your sign-in goes only to trusted servers**: The OIDC token lets whoever receives it act as you. It was sent to whatever server address was configured. It now goes only to the built-in server or one you approved. The check and the connection use the same normalized `scheme://host:port`, so user-info, case and default-port tricks resolve to the real host.
- **Developer keys still work anywhere**: An API key is issued by the server it is set for, so it is sent without asking. A server you haven't trusted with your sign-in gets the key instead when one is set.

### Auto-paste
- **No unsolicited pastes**: Any `transcription` frame used to be copied and pasted into the focused window, even when you weren't dictating. The client now accepts one only after it has sent end-of-stream, and only the first. The wait ends on that reply, after two minutes, or when the connection drops.
- **Plain text only**: A transcript that isn't text is refused. Accepted text is sanitized and pasted on one line.
- **Wider sanitizer**: `TextSanitizer` now strips every ANSI CSI sequence (screen clears and cursor modes included) and every OSC sequence (titles and hyperlinks, ended by BEL or ST). It also strips bidi override and isolate characters, which can make pasted code display differently from what it is ("Trojan Source"). The zero-width joiners that real scripts and emoji need are kept.
- **Server error text is inert**: Error messages from the server are sanitized, shown on one line, and capped at 160 characters. The home screen no longer opens a dialog when an error's wording matches a pattern.

### Transport and privacy
- **Local `ws://` checks every address**: A `ws://` hostname counts as local only when every address it resolves to is private or loopback, not just the first. Loopback is checked by address instead of a `127.` text prefix.
- **Trusted update links**: The client opens only HTTPS `github.com` pages under its own repository, and release checks time out after 10 s.
- **Quieter logs**: The client logs a transcript's length, never its text, and a short subject prefix instead of the email. Provider error bodies are logged as short summaries. Clearing history now vacuums the database so deleted rows don't linger in the file.

## Reliability

### Connection
- **Sign-in vs connection**: "Signed in" now means holding a sign-in or key. The normal idle disconnect no longer reads as signed out, and an offline server shows `[ server offline ]` with **Try again** instead of "Sign in".
- **Real backoff**: Retries after a drop or an unreachable server wait 2 s, 4 s, 8 s and so on, up to once a minute, until one succeeds. Retries stop on sign-out, in Groq mode, after a ban, or when the server rejects the sign-in.
- **No leaked sockets**: A failed or superseded connect closes its socket. Each socket only reports while it is current, so a stale one closing late can't tear down its replacement. A handshake that times out disconnects instead of hanging in "connecting".
- **Connect means ready**: `connect()` resolves once the server accepts the sign-in, and concurrent callers share one attempt instead of opening a second socket.
- **No lost endings**: An end-of-stream sent while the handshake is still running waits for the buffered audio and follows it.
- **Groq mode stays dormant**: Switching to Groq while a connection is opening no longer reconnects to the backend. Settings changed in Groq mode are recorded rather than replayed as a reconnect later.

### Dictation
- **No silent losses**: If the connection drops mid-dictation, recording stops and the client says the dictation wasn't transcribed, naming the reason when it knows it (offline, refused address, untrusted server).
- **A recorder that stops by itself still transcribes**: What it captured is sent, with no doubled audio in later recordings.
- **Second press while starting**: Pressing the shortcut again while the microphone is still opening now stops the recording once it starts.
- **Paste before history**: The paste runs first, so a failed history save can no longer cost you the text.
- **Groq clean-up**: Up to 24 MB of buffered audio is dropped after a failed upload and in incognito.

### Window and exit
- **The process ends on close**: Closing the window always wakes the hotkey thread, which blocks in native `GetMessageW`. The app no longer lingers without a window, holding the single-instance lock.
- **Native window**: The runner now creates a borderless, square, shadowless window sized to exactly 420×600 before Flutter starts. This replaces the `window_manager` setup that `main.dart` used to run at startup.

## Captions Interface

- **Home**: One cue states what is happening (`[ ready ]`, `[ listening ]`, `[ transcribing ]`, `[ server offline ]` …), the single fix for a blocked state sits under it, and the last transcript is set as captions with its age.
- **Pixel meter**: A retro meter moves at display refresh while recording, against an adaptive noise floor and peak, so quiet and loud microphones both read well.
- **Moving contour map**: A GPU-drawn topography lies behind the idle home screen. It answers the cursor and clicks, flattens while you dictate, and can be turned off (**Settings → Moving background**) for slower computers.
- **Panels**: Account, Settings, History and Logs are full-window panels with one header, row and rule style. Dialogs remain only for confirmations, the shortcut recorder and the style editor.
- **Details**: Buttons press down 2 px and climb back. Every control is square like the window. Text sits on whole pixels for crisper rendering. Error notices stay up for 4 s. Esc closes the shortcut recorder, and deleting a custom style asks first.

## Testing & Quality Gates

- **Flutter client**: `flutter analyze` clean; DCM reports no issues; 372 tests passing (239 in v3.1.0). New suites cover the home states, the trust gate and handshake, stale sockets and backoff, the transcript gate and line breaks per style, the sanitizer's new sequences, the contour motion and the press animation. The WebSocket tests no longer open real network connections.
- **Backend**: `test_privacy.py` now checks that no log line at any level holds the transcript, in either mode. CI runs the full suite and the Docker end-to-end test.
- **Terminal client**: unchanged except for a typed test helper.
