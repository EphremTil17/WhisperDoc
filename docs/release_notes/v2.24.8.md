# WhisperDoc Technical Release Notes - v2.24.8
**Version Range: v2.24.7 to v2.24.8**

This release introduces dynamic Groq Cloud model selection to the Flutter client, enabling users to switch seamlessly between the fast `whisper-large-v3-turbo` model and the full-depth `whisper-large-v3` model. Additionally, this version introduces a declarative, repository-wide automated version bumper tool (`scripts/bump_version.py`) that synchronizes version strings and lockfiles across all components.

---

## Flutter Client: Dynamic Groq Model Selection

### Responsive Settings UI & Model Selector
- **Side-by-Side Model & Language Control**: Refactored the Language Hint row in `groq_fields.dart` into a responsive side-by-side layout pairing an ISO-639-1 validated `TextField` on the left with a dark-glassmorphism `DropdownButtonFormField` on the right.
- **Model Choice**: Supports both `whisper-large-v3-turbo` (default, lowest latency) and `whisper-large-v3` (maximum depth and verbatim accuracy).
- **Settings Persistence & Validation**: Added `_groqModel` state and `SharedPreferences` persistence in `SettingsService`. Incoming model identifiers are trimmed and validated against supported models with safe fallbacks.
- **Enclave Hardening**: Guaranteed unconditional, idempotent `SecureVault.initialize()` execution during settings load to prevent uninitialized vault access during startup.
- **Dynamic Request Dispatch**: Updated `GroqHttpClient` and `GroqTranscriptionService` to inject the selected model dynamically into multipart audio transcription requests.

---

## Tooling & Automation: Automated Version Bumper

### Declarative Multi-Component Synchronization
- **`scripts/bump_version.py`**: Created an automated SemVer bumper utility supporting `patch`, `minor`, `major`, and explicit target versions.
- **Declarative Target Rules**: Enforces single-source-of-truth updates across `backend/pyproject.toml`, `backend/.env.template`, `flutter_client/pubspec.yaml`, Inno Setup installer scripts, and `terminal_client/` configs.
- **Lockfile Synchronization**: Automatically invokes `uv lock` in `backend/` and `terminal_client/` to keep lockfiles in sync.
- **Preflight & Dry-Run Safety**: Validates regex patterns before applying changes, with a `--dry-run` flag to inspect planned updates safely.

---

## Test & Verification Coverage
- Added unit test suite `flutter_client/test/services/transcription/groq_error_test.dart` and `settings_service_test.dart` verifying model selection, whitespace trimming, and invalid model fallbacks.
- Added unit test suite `backend/tests/test_version_bumper.py` validating SemVer arithmetic, target regex integrity, and lockfile synchronization error handling.
- All Flutter and Terminal client test suites pass with zero analyzer issues.
