# WhisperDoc Technical Release Notes - v3.1.0
**Version Range: v3.0.0 to v3.1.0**

v3.1.0 is the first release of WhisperDoc's security maintenance phase. It closes all 44 open Dependabot advisories, fixes a client-IP spoofing hole that undermined IP banning, and stops unauthenticated clients from making the server buffer large uploads. It also fixes sanitizers that corrupted non-ASCII dictation in all three components, and repairs connection and startup lifecycles across the Flutter client, the terminal client, and the backend. No new user-facing features are added. The work makes existing behavior correct, bounded, and safe.

---

## Upgrade Notes

Read these before deploying the backend:

- **Compose service renamed**: `whisper-backend` is now `backend`. Update any scripts that run `docker compose ... whisper-backend`. `COMPOSE_PROFILES` is now derived from `ASR_ENGINE` (`COMPOSE_PROFILES=${ASR_ENGINE}`). Existing `.env` files that set `COMPOSE_PROFILES=parakeet` keep working.
- **`POST /log` removed**: The endpoint accepted unauthenticated writes and had no remaining caller.
- **`POST /transcribe` contract tightened**: Requests must send `Authorization: Bearer <key>` and a `Content-Length` header (chunked uploads get 411). Bodies over 25 MB get 413. Internal failures return `Transcription failed (ref <id>)`; the id matches a server log line.
- **Forwarded-header trust**: The images now trust `X-Forwarded-For` only from `172.16.0.0/12` and `192.168.0.0/16` (Docker bridge networks, where host-side cloudflared arrives). If your reverse proxy reaches the container from another network, set `FORWARDED_ALLOW_IPS` in `.env`. Never use `*`.
- **New optional settings**: `FFMPEG_TIMEOUT_SECONDS` (default `60`) bounds HTTP upload conversion. `SANITIZE_TRANSCRIPTS` (default `true`) gates output sanitization and should stay enabled outside benchmarking.
- **Terminal client**: `CLIENT_VERSION` is no longer read from `.env`. The version comes from the installed package, so upgraded clients stop announcing a stale version and being rejected as `VERSION_OUTDATED`.
- **Installers move to GitHub Releases**: The Windows installer is no longer committed under `win_x64_release/`. The Release workflow builds it from the tagged commit and attaches it to the GitHub Release.
- **Leaner Whisper image**: PyTorch was removed (5.23 GB to 4.3 GB). The newer CUDA libraries in this release add back about 0.5 GB on disk (4.84 GB), with no change in VRAM. Rebuild with `docker compose build backend`.
- **uv 0.13 required**: The lockfiles use uv's newer format. Update uv to 0.13.9 or later (`uv self update`) on every machine that runs the backend or terminal client, including WSL.
- **Flutter 3.50 to build the client**: The client requires Flutter 3.50.1 (Dart 3.14) and the `material_ui` package. Run `flutter upgrade` before building locally.

## Security

### Dependency Advisories
- **44 Dependabot alerts closed** (39 in `backend/uv.lock`, 5 in `terminal_client/uv.lock`). An OSV scan of every pinned package, including `flutter_client/pubspec.lock`, reproduced exactly that set.
- **PyJWT** carried 15 advisories, including a critical asymmetric-PEM confusion bypass. None were reachable: WhisperDoc pins `RS256`, verifies against a constructed `RSAPublicKey`, and never uses `PyJWKClient`. It is upgraded to 2.15.1 regardless.
- **Floors, not just bumps**: Each fixed version is recorded in `constraint-dependencies` with its GHSA IDs, so a later re-resolve cannot regress to a vulnerable release.

### Backend
- **Client-IP spoofing closed**: Trusting every proxy hop (`--forwarded-allow-ips='*'`) made uvicorn take the caller-controlled leftmost `X-Forwarded-For` entry. Flooders could rotate it to dodge bans, or name a victim's IP to get that victim banned.
- **Pre-parse upload guard**: FastAPI dependencies run after Starlette has parsed the multipart body. The bearer-token, `Content-Length`, and size checks therefore moved into middleware that runs on headers alone.
- **Bounded ffmpeg**: Conversion runs with `-nostdin`, a wall-clock timeout, and a duration cap equal to the WebSocket buffer limit. A crafted file cannot hang a worker or expand into an unbounded PCM stream.
- **HTTP/WebSocket parity**: HTTP transcriptions share the per-user concurrency semaphore and the same segment sanitizer, log only character counts, and never echo internal exception text.
- **OIDC hardening**: Token validation runs off the event loop, so a slow identity provider no longer stalls every connection. Discovery and JWKS caches are lock-guarded. A signing key id missing from the cache triggers one JWKS refetch, at most once a minute, so key rotation works without a restart and forged key ids cannot be used to hammer the provider.

### Clients
- **Unicode-preserving sanitizers**: All three components used a printable-ASCII whitelist that turned "café" into "caf" and dropped non-Latin scripts entirely, breaking 98 of the 99 languages Groq mode advertises. They now strip only ANSI sequences and C0/C1 control characters, so escape sequences stay inert and real text survives.
- **Safe auto-paste**: When another app held the clipboard, the Flutter client used to simulate Ctrl+V anyway and paste whatever was already there, possibly a password. Paste now runs only after a confirmed copy.

## Reliability

### Flutter Client
- **No more white flash or frozen launch**: The window was shown before services initialized, while an untimed OIDC refresh could hang on the network. The window is now configured hidden, `runApp()` runs immediately, and the runner shows the window on a branded boot frame. Setup errors are displayed instead of hanging.
- **Offline launches keep you signed in**: The client used to sign out on any refresh exception, so a network failure wiped a valid refresh token. Sign-out now happens only when the provider rejects the token (HTTP 400/401). Identity requests time out after 10 s, and the vault's PBKDF2 key derivation runs on a worker isolate.
- **Microphone hot-plug**: A native `IMMNotificationClient` pushes Windows Core Audio device events to Dart, coalescing each burst into a single re-check with no polling. A re-plugged microphone is picked up without pressing the hotkey. A missing selected device falls back to the system default, and a failed device listing no longer reports "No microphone detected" when a device is present.
- **Recording races**: Overlapping stop requests could upload and paste the same clip twice, and overlapping starts could open a second capture stream. Both transitions are now claimed synchronously.
- **Error routing by `error_code`**: Any server error whose text contained "Auth" was treated as a failed login, and the NO_AUDIO check compared a number with a string, so its hint never appeared. Routing now uses the structured `error_code`, the same lesson recorded as Lesson 15.

### Terminal Client
- **Idle timeout works**: Keepalive pings and pongs no longer count as activity. A single watchdog per connection replaces the timer that was recreated on every audio chunk.
- **Sane reconnection**: Backoff resets only after authentication. Idle evictions and rejected API keys no longer trigger endless reconnects. Teardown no longer cancels itself, and concurrent connects are serialized.
- **Ordered utterances**: Each capture session gets its own queue. Stop flushes queued audio before sending end-of-stream, and stopping before authentication completes now waits (bounded) for the handshake instead of silently discarding the audio.

### Backend
- **Owned background tasks**: `ConnectionManager` no longer starts tasks in its constructor. The lifespan calls `start()` and `stop()`, concurrent handshakes share one model warmup, and the Whisper idle monitor's blocking unload runs on a daemon thread instead of the event loop.
- **Recoverable startup**: Initialization failures re-raise so Docker's restart policy retries. `/health` reports model residency without failing when Whisper idle-unloads by design.
- **Tracker hygiene**: Expired IP bans are pruned by the periodic sweep instead of lingering until that IP reconnects.

## Performance & Cleanup

- **Whisper image −0.9 GB**: Torch was installed only to call `torch.cuda.empty_cache()`, which never ran with a CPU wheel. CTranslate2 frees its own CUDA memory.
- **Narrower UI rebuilds**: Widgets subscribe only to the state they render, history entries are decrypted once per dialog, and pulsing buttons no longer smear from restarted implicit tweens.
- **Dead code removed**: Client-to-server log forwarding, unused widgets and getters, a write-only counter, and the terminal `whisper_client.py` shim are gone. History is now pruned to the newest 100 entries instead of growing without bound.

## Dependency Refresh

Every direct dependency of the three components is on its latest release, and the build toolchain moved with them.

- **Backend & terminal client**: FastAPI 0.165, uvicorn 0.54, websockets 17, cachetools 8, loguru 0.8, and the GPU stack (ctranslate2 4.9, cuDNN 9.28, cuBLAS 12.9). The images and CI use uv 0.13.9 and static-ffmpeg 9.0.2. PyAV stays below 19: that release removed an argument faster-whisper still passes, which broke every transcription. The Docker end-to-end test caught it before release.
- **Flutter client**: Flutter 3.50.1 with win32 6, record 7, window_manager 0.7 (native window API), flutter_web_auth_2 6, google_fonts 9, drift 2.35, and Material from the separate `material_ui` package. The discontinued `screen_retriever` packages and the end-of-life `sqlite3_flutter_libs` are gone.
- **Verified unchanged**: the vault key behind the encrypted history, the stored-credential file, and the 16 kHz mono capture format, all checked against package source. GPU memory with large-v3-turbo is the same or slightly lower.
- **Fixes from the migration**: under win32 6, a hotkey-loop error would have spun a CPU core, so the loop now reads GetMessage's raw return. The chime fallback no longer leaks a string on every play. A microphone unplugged mid-recording now continues on the default device instead of silently pausing.
- **Settings dropdowns**: the audio input and Groq model pickers are a compact dropdown in the app's glass menu style and font. They replace Material dropdowns that had fallen back to the system font.

## CI/CD

- **Checks on every push**: pre-commit hooks, backend pyright and pytest, terminal client and Flutter suites on Windows, and a Flutter release build that compiles the native runner.
- **Docker end-to-end test**: CI builds the Whisper image, runs it on CPU with `tiny.en` under the production isolation flags, transcribes `jfk.flac`, asserts the 401 / 411 / 404 rejections and the read-only root filesystem, and runs the live API and WebSocket tests.
- **Tagged releases**: a `vX.Y.Z` tag checks versions, notes, and mainline ancestry, then builds the obfuscated installer on a clean runner and creates a draft GitHub Release. Installed clients only see the update once the draft is published.
- **Supply chain**: actions are pinned to commit SHAs and updated by Dependabot; `bump_version.py --check` blocks version drift.
